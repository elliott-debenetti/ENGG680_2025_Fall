# Assignment 2: Introduction to Non-linear Square and Machine Learning

## Description

This assignment explores machine learning fundamentals through three real-world applications. Our group will implement least squares estimation and gradient descent for vehicle positioning in autonomous driving systems, develop a logistic regression model to predict student depression levels, and build neural networks (MLP and CNN) to classify handwritten digits from the MNIST dataset. The assignment combines numerical optimization techniques with modern machine learning methods, emphasizing practical implementation in Python, collaborative development through Git, and model evaluation through cross-validation and hyperparameter tuning.
